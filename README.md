# Test Application for SHIFT

## Используемые технологии

- SnapKit
- Alamofire

## Требования

- iOS 15 и выше.
- После клонирования репозитория необходимо установить зависимости для библиотек CocoaPods так:
  
  **cd *путь к проекту* /testTaskShiftIOS**

  **pod install**

  _**Возможно, для корректной установки библиотек, потребуется изменить версию objectVersion на 63 в project.pbxproj**_
